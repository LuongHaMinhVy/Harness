# Rubric chấm bài sum-array (thang 10 điểm)

| Tiêu chí | Test tương ứng | Điểm |
|---|---|---|
| Cộng đúng số dương | `số dương` | 2 |
| Cộng đúng số âm và thập phân | `số âm và thập phân` | 2 |
| Đúng với mảng một phần tử | `một phần tử` | 2 |
| Mảng rỗng trả về 0 | `mảng rỗng` | 1 |
| Ném TypeError khi đầu vào không phải mảng | `không phải mảng` | 1 |
| Chất lượng code: tên biến rõ ràng, không dùng `var`, không dùng biến toàn cục | đọc code | 2 |

Quy tắc:
- Điểm của 5 tiêu chí đầu chỉ dựa vào kết quả `run_tests`, không tự suy đoán.
- Bài không chạy được (lỗi cú pháp, timeout) thì 5 tiêu chí đầu được 0 điểm; chất lượng code chấm tối đa 0 vì không có code chạy được.
- Nhận xét phải nêu cụ thể test nào trượt và lỗi chất lượng code nào (nếu có).
