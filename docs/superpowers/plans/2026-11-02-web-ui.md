# Web UI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm giao diện web localhost (chat + log + duyệt, đánh giá, bảng điểm) dùng lại phần lõi của harness.

**Architecture:** Server Hono một tiến trình phục vụ API + SSE + file React đã build. `webSession` bọc phần lõi và phát `HarnessEvent`; giao diện React dựng trạng thái bằng một reducer thuần từ `StateSnapshot` + sự kiện. Kiểu dữ liệu dùng chung nằm ở `src/shared/events.ts`.

**Tech Stack:** Hono, @hono/node-server, React 19, Vite, TypeScript, zod, vitest; phần lõi `ai` v7 + `@ai-sdk/google`.

**Spec:** `docs/superpowers/specs/2026-11-02-web-ui-design.md` (bổ sung cho `2026-11-02-grading-harness-design.md`)

## Global Constraints

- Server chỉ lắng nghe `127.0.0.1`, cổng `PORT` (mặc định 3000).
- Không dùng `dangerouslySetInnerHTML`; không trả stack trace cho trình duyệt; API key không có trong response.
- Mọi body POST validate bằng zod từ `src/shared/events.ts`.
- Một việc mỗi lúc (câu hỏi hoặc eval); bận → 409.
- Yêu cầu duyệt tự từ chối sau 300000 ms.
- CLI (`pnpm start`, `pnpm eval`) giữ nguyên hành vi.
- Thông báo cho người dùng bằng tiếng Việt.
- Dùng pnpm.

## Review Focus

1. Hai `save_grade` trong cùng một lượt: hai thẻ duyệt hiện cùng lúc, bấm từng cái đều được, không treo (Task 3).
2. Trình duyệt đóng trong lúc chờ duyệt: tự từ chối sau 5 phút, agent chạy tiếp, `busy` về false (Task 3).
3. Mở lại trang hoặc SSE kết nối lại giữa chừng một câu hỏi: snapshot có các lượt đã chạy và thẻ duyệt đang chờ (Task 4).
4. Câu trả lời của model chứa `<script>`/HTML: hiển thị dạng chữ, không thực thi (Task 6, kiểm tra trên trình duyệt).
5. `POST /api/reset` khi đang bận bị từ chối, lịch sử không bị xoá giữa chừng (Task 5).

### Task 3: `webSession`

**Produces:**
```ts
export type WebSessionDeps = { model: LanguageModel; modelName: string; dataDir: string; gradesFile: string; evalGradesFile: string; cacheFile: string; logDir: string; goldenFile: string; maxSteps: number; approvalTimeoutMs?: number; evalPauseMs?: number; evalWaitMs?: number };
export function createWebSession(d: WebSessionDeps): {
  subscribe(fn: (e: HarnessEvent) => void): () => void;
  snapshot(): StateSnapshot;
  ask(question: string): 'started' | 'busy';
  approve(id: string, approved: boolean): boolean;
  setMaxSteps(n: number): void;
  reset(): boolean;            // false khi bận
```
